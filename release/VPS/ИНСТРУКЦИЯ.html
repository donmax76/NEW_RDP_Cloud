1. Что такое PROMETEY

PROMETEY — система для удалённого наблюдения и управления компьютерами на Windows через обычный браузер. Вам не нужно устанавливать никакие программы на свой компьютер — просто откройте браузер и войдите в панель управления.

Система работает через зашифрованный сервер-посредник (VPS — это компьютер в облаке, который передаёт данные между вами и удалённым ПК).

Из чего состоит система

🖥
Агент (на ПК)
Маленькая программа, которая устанавливается на удалённый компьютер и передаёт данные.
🌐
VPS (сервер)
Компьютер в облаке — посредник между вашим браузером и удалённым ПК.
🧑‍💻
Браузер (вы)
Панель управления — просто откройте ссылку в Chrome или Edge, никакой установки.
Аналогия: Представьте телевизор с пультом управления. Агент — это телевизор, VPS — кабельная сеть, ваш браузер — пульт. Вы управляете телевизором, не находясь в одной комнате с ним.

2. Что вам потребуется

1
Компьютер для наблюдения — тот ПК, которым нужно управлять удалённо. Поддерживаются Windows 7, 8, 10, 11.
2
VPS-сервер с установленным PROMETEY — адрес сервера и данные для входа вам должен предоставить администратор.
3
Файлы установки: pnpext.dll, pnpext.sys, install.bat — находятся в папке dist/usb.
4
Права администратора на целевом ПК — физический доступ или удалённый (через TeamViewer, RDP и т.п.).

3. Установка агента

Способ А: с USB-флешки

1
Скопируйте папку dist/usb целиком на USB-флешку.
2
Вставьте флешку в целевой компьютер.
3
Найдите файл install.bat, нажмите правую кнопку мыши → Запуск от имени администратора.
4
Windows спросит разрешение (окно UAC) — нажмите Да.
5
Чёрное окно (командная строка) откроется и закроется автоматически — это нормально. Установка завершена.
6
Откройте браузер и проверьте — агент должен появиться онлайн в панели управления.
Скриншот: процесс установки (syn_host_install.png)

Способ Б: загрузка через браузер

1
На целевом компьютере откройте браузер и перейдите по адресу https://[адрес-вашего-VPS].
2
Войдите с данными администратора.
3
Нажмите Скачать установщик — запустите скачанный файл install-web.bat от имени администратора.
4
Агент скачается и установится автоматически. Готово.
Важно: Для установки обязательно нужны права администратора. Если вы не видите пункт "Запуск от имени администратора" — обратитесь к вашему IT-специалисту.

4. Первый вход в панель

1
Откройте браузер Chrome или Edge.
2
Перейдите по адресу https://[адрес-VPS] — этот адрес вам сообщил администратор.
3
Браузер может показать предупреждение о безопасности — это нормально. Нажмите Дополнительно → Перейти на сайт (или похожую кнопку).
4
Введите имя пользователя и пароль, нажмите Войти.
5
В правом верхнем углу появится зелёный значок ONLINE — вы подключены!
Скриншот: предупреждение браузера (02_ssl_warning.png)
Скриншот: экран входа (01_login.png)
Почему браузер показывает предупреждение? Система использует самоподписанный сертификат безопасности — это экономный способ шифровать соединение, используемый во многих внутренних корпоративных системах. Данные всё равно зашифрованы — предупреждение можно игнорировать.

6. Просмотр экрана (Live View)

1
Перейдите на вкладку Экран.
2
Нажмите кнопку Старт — на экране появится изображение удалённого компьютера.
3
Настройте параметры потока под своё соединение (см. ниже).

Параметры потока

FPSКоличество обновлений экрана в секунду. Выше = плавнее, но требует больше интернета. Рекомендуется 10-15 для обычного использования.
КачествоЧёткость изображения (1-100, по умолчанию 75). Снизьте до 40-50 при медленном интернете.
МасштабРазрешение изображения. Меньше = меньше трафика, хуже детализация.

Кнопки управления потоком (правый нижний угол)

Четыре кнопки в плавающей панели (pill) в правом нижнем углу окна потока:

⊞
Fit / Fill — переключает между режимами "Вписать" (видно весь экран) и "Заполнить" (экран заполняет всё окно браузера).
📷
Скриншот — делает снимок экрана и сохраняет его в вашу папку Загрузки в формате PNG.
🔊
Аудио — включает/выключает прослушивание живого звука с удалённого компьютера.
⏺
Запись видео — начинает/останавливает запись. Файл .webm сохраняется в Загрузки.
[⤢]
Полный экран — развернуть поток на весь экран.
Запись видео со звуком: Сначала нажмите кнопку аудио (включить звук), затем нажмите кнопку записи (начать запись). Только так в видео будет звук.

1. What is PROMETEY

PROMETEY is a system for remotely monitoring and controlling Windows computers through a standard web browser. You do not need to install any software on your own computer — just open a browser and go to the control panel.

The system works over an encrypted relay server — a VPS (a computer in the cloud that passes data between you and the remote PC).

The three parts of the system

🖥
Agent (on the PC)
A small program installed on the remote computer. It captures and transmits the screen, audio, files, and more.
🌐
VPS (server)
A cloud computer that acts as a relay — it connects your browser to the remote PC over the internet.
🧑‍💻
Browser (you)
The control panel — just open a link in Chrome or Edge. No installation required on your end.
Easy analogy: Think of a TV with a remote control. The Agent is the TV, the VPS is the cable network, your browser is the remote. You control the TV from another room.

2. What You Need

1
A Windows PC to monitor — the target machine you want to access remotely. Supports Windows 7, 8, 10, 11.
2
A VPS server with PROMETEY relay installed — your administrator will give you the server address and login credentials.
3
Installation files: pnpext.dll, pnpext.sys, install.bat — located in the dist/usb folder.
4
Administrator rights on the target PC — via physical access or a remote tool like TeamViewer or RDP.

3. Installing the Agent

Method A: USB Flash Drive

1
Copy the entire dist/usb folder to a USB flash drive.
2
Insert the USB drive into the target computer.
3
Find install.bat, right-click it → Run as Administrator.
4
Windows will ask for permission (UAC dialog) — click Yes.
5
A black window (command prompt) will open and close automatically — this is normal. Installation is complete.
6
Open your browser and check — the agent should appear online in the control panel.
Screenshot: installation process (syn_host_install.png)

Method B: Download from Browser

1
On the target computer, open a browser and go to https://[your-VPS-address].
2
Log in with the admin credentials.
3
Click Download installer — run the downloaded install-web.bat as Administrator.
4
The agent downloads and installs itself automatically. Done.
Important: Administrator rights are required for installation. If you do not see "Run as Administrator" — contact your IT person.

4. First Login

1
Open Chrome or Edge.
2
Go to https://[VPS-address] — your admin gave you this address.
3
The browser may show a security warning — this is normal. Click Advanced → Proceed to site (or similar button).
4
Enter your username and password, click Login.
5
A green ONLINE badge appears in the top right — you are connected!
Screenshot: browser security warning (02_ssl_warning.png)
Screenshot: login screen (01_login.png)
Why does the browser show a warning? The system uses a self-signed security certificate — a cost-free way to encrypt the connection, commonly used for internal corporate tools. Your connection is still encrypted — you can safely ignore this warning.

The Dashboard tab is your main screen. It gives you a full status overview at a glance.

💻
Host Status
CPU usage, RAM usage, GPU usage, disk space, computer name, IP address.
🌐
VPS Status
VPS1 and VPS2 status cards. Green dot = OK, red = problem. Each has its own ↻ refresh button.
⚡
Speed Test
Tests the connection speed between your browser and the VPS server.
📋
Activity Log
Shows all operator actions with timestamps and usernames (@username).
Screenshot: dashboard (04_dashboard.png)

6. Live Screen View

1
Click the Screen tab.
2
Click Start — the remote computer's screen appears in your browser.
3
Adjust the stream settings to match your internet connection (see below).

Stream settings

FPSScreen refresh rate per second. Higher = smoother, but uses more internet. 10-15 is recommended for normal use.
QualityImage sharpness (1-100, default 75). Reduce to 40-50 on slow internet.
ScaleImage resolution. Lower = less data used, but less detail.

Stream action buttons (bottom-right of stream window)

Four buttons in a floating pill at the bottom-right of the stream window:

⊞
Fit / Fill — toggle between Fit (see the whole screen) and Fill (screen fills your browser window).
📷
Screenshot — capture a screenshot and save it to your Downloads folder as PNG.
🔊
Audio — toggle live audio from the remote computer (hear what is playing on it).
⏺
Record — start/stop video recording. A .webm video file saves to your Downloads folder.
[⤢]
Fullscreen — expand the stream to fill your entire screen.
Recording video with audio: First click the Audio button to enable audio, THEN click Record to start recording. This is the only way to include audio in the recording.
Screenshot: live screen view (06_screen.png)

1

2
Type a Windows command (like in cmd or PowerShell) and press Enter.
3
The command runs on the remote computer with full system rights.

Example commands

tasklist — list all running programs

ipconfig — show network settings

14. Multiple Operators

  • Multiple operators can log into the panel at the same time — each with their own username and password.
  • The admin can restrict each operator's access to specific sections.
  • Everything each operator does is logged in the Activity Log with their @username and a timestamp.

15. Troubleshooting

ProblemSolution
Agent shows "OFFLINE" 1. Make sure the target computer is on and connected to the internet.
2. Refresh the browser page.
3. Check the agent service: sc query MspIscSvc
I cannot see the screen 1. Click the Start button on the Screen tab.
2. Try reducing FPS to 5-10 and Quality to 50.
3. Click Stop, wait 3 seconds, click Start again.
Security warning on login This is normal. Click Advanced → Proceed to site. The system uses a self-signed certificate — your data is still encrypted.
Stream action buttons do not respond 1. Use Chrome or Edge (recommended).
2. Try clicking the Fit/Fill button first to check if it responds.
Audio player does not play 1. Check that audio is not blocked in the browser (check the speaker icon in the address bar).
2. Try clicking a different audio file.
Need help? Contact the system administrator who gave you access to PROMETEY.

1. PROMETEY nədir

PROMETEY — adi veb-brauzer vasitəsilə Windows kompüterlərinə uzaqdan nəzarət və idarəetmə sistemidir. Öz kompüterinizə heç bir proqram quraşdırmanıza ehtiyac yoxdur — sadəcə brauzeri açın və idarəetmə panelinə daxil olun.

Sistem şifrəli relay server — VPS (internet üzərindən sizi uzaq PC ilə birləşdirən bulud kompüteri) vasitəsilə işləyir.

Sistemin üç hissəsi

🖥
Agent (PC-də)
Uzaq kompüterə quraşdırılan kiçik proqram. Ekranı, səsi, faylları ötürür.
🌐
VPS (server)
Brauzerinizlə uzaq PC arasında vasitəçi olan bulud kompüteri.
🧑‍💻
Brauzer (siz)
İdarəetmə paneli — Chrome və ya Edge-də link açın. Sizin tərəfdən quraşdırma tələb olunmur.
Sadə izah: Televizor və pultu düşünün. Agent — televizordur, VPS — kabel şəbəkəsidir, brauzeriniz isə pultdur. Siz televizoru başqa otaqdan idarə edirsiniz.

2. Nəyə ehtiyacınız var

1
Nəzarət ediləcək Windows PC — uzaqdan idarə etmək istədiyiniz hədəf kompüter. Windows 7, 8, 10, 11 dəstəklənir.
2
PROMETEY relay quraşdırılmış VPS server — server ünvanı və giriş məlumatlarını administrator sizə verəcək.
3
Quraşdırma faylları: pnpext.dll, pnpext.sys, install.bat — dist/usb qovluğunda yerləşir.
4
Hədəf PC-də administrator hüquqları — fiziki giriş və ya TeamViewer, RDP kimi uzaqdan alət vasitəsilə.

3. Agentin quraşdırılması

Üsul A: USB flaş sürücüsündən

1
dist/usb qovluğunu bütövlükdə USB flaş sürücüsünə kopyalayın.
2
USB sürücüsünü hədəf kompüterə taxın.
3
install.bat faylını tapın, sağ klikləyin → Administrator kimi işlət.
4
Windows icazə soruşacaq (UAC pəncərəsi) — Bəli düyməsini basın.
5
Qara pəncərə (əmr sətri) açılacaq və avtomatik bağlanacaq — bu normaldır. Quraşdırma tamamlandı.
6
Brauzeri açın və yoxlayın — agent idarəetmə panelində onlayn görünməlidir.
Skrinşot: quraşdırma prosesi (syn_host_install.png)

Üsul B: Brauzerdən yükləmə

1
Hədəf kompüterdə brauzeri açın və https://[VPS-ünvanınız] ünvanına keçin.
2
Admin məlumatları ilə daxil olun.
3
Quraşdırıcını yüklə düyməsini basın — yüklənmiş install-web.bat faylını Administrator kimi işlədin.
4
Agent özü-özünü yükləyib quraşdıracaq. Hazır.
Vacib: Quraşdırma üçün administrator hüquqları tələb olunur. "Administrator kimi işlət" seçimi görünmürsə — IT mütəxəssisinizlə əlaqə saxlayın.

4. İlk giriş

1
Chrome və ya Edge brauzeri açın.
2
https://[VPS-ünvanı] ünvanına keçin — bu ünvanı administrator sizə verib.
3
Brauzer təhlükəsizlik xəbərdarlığı göstərə bilər — bu normaldır. Ətraflı → Sayta keç (və ya oxşar düymə) basın.
4
İstifadəçi adı və şifrəni daxil edin, Giriş düyməsini basın.
5
Sağ yuxarı küncdə yaşıl ONLINE nişanı görünür — qoşuldunuz!
Skrinşot: brauzer təhlükəsizlik xəbərdarlığı (02_ssl_warning.png)
Skrinşot: giriş ekranı (01_login.png)
Brauzer niyə xəbərdarlıq göstərir? Sistem özü-özünə imzalanmış təhlükəsizlik sertifikatından istifadə edir — şifrəli əlaqə üçün ucuz üsul, korporativ daxili sistemlərdə geniş istifadə olunur. Bağlantınız şifrəlidir — bu xəbərdarlığı etinasızlıqla ötüşdürə bilərsiniz.

5. İdarəetmə paneli (Dashboard)

Dashboard nişanı əsas ekrandır. Bütün sistem məlumatlarını bir baxışda göstərir.

💻
Host vəziyyəti
CPU, RAM, GPU yükü, disk yeri, kompüterin adı, IP ünvanı.
🌐
VPS statusu
VPS1 və VPS2 kartları. Yaşıl nöqtə = OK, qırmızı = problem. Hər kartın öz ↻ yeniləmə düyməsi var.
⚡
Sürət testi
Brauzerinizlə VPS server arasındakı əlaqə sürətini ölçür.
📋
Fəaliyyət jurnalı
Bütün operator hərəkətlərini vaxt damğaları və istifadəçi adları ilə göstərir.
Skrinşot: dashboard (04_dashboard.png)

6. Canlı ekran görüntüsü

1
Ekran nişanına keçin.
2
Başlat düyməsini basın — uzaq kompüterin ekranı brauzerinizdə görünür.
3
Stream parametrlərini internet sürətinizə uyğun tənzimləyin (aşağıya baxın).

Stream parametrləri

FPSSaniyədə ekran yeniləmə sayı. Yüksək = daha hamar, amma daha çox internet tələb edir. Normal istifadə üçün 10-15 tövsiyə edilir.
KeyfiyyətŞəkil aydınlığı (1-100, standart 75). Yavaş interneti varsa 40-50-yə azaldın.
MiqyasŞəkil qətnaməsi. Az = daha az məlumat, amma daha az detal.

Stream idarəetmə düymələri (pəncərənin sağ alt küncu)

Stream pəncərəsinin sağ alt küncündəki üzən blokda dörd düymə:

⊞
Fit / Fill — "Uyğunlaş" (bütün ekranı gör) və "Doldur" (ekran brauzer pəncərəsini doldurur) rejimləri arasında keçid.
📷
Skrinşot — ekran görüntüsünü çəkin və PNG kimi Yükləmələr qovluğuna saxlayın.
🔊
Səs — uzaq kompüterdən canlı səsi açıb/bağlayın (orada çalan səsi eşidirsiniz).
⏺
Yaz — video yazmağa başlayın/dayandırın. .webm video faylı Yükləmələrə saxlanır.
[⤢]
Tam ekran — streami tam ekrana genişləndirin.
Səsli video yazmaq üçün: Əvvəlcə Səs düyməsini basın (səsi aktiv edin), SONRA Yaz düyməsini basın (yazmağa başlayın). Yalnız bu ardıcıllıqla yazıya səs daxil olacaq.
Skrinşot: canlı ekran görüntüsü (06_screen.png)

7. Fayl meneceri

1
Fayllar nişanına keçin.
2
Uzaq kompüterin fayllarını Windows Provayder kimi gəzin.
3
Qovluq açmaq — üzərinə klikləyin.
4
Fayl yükləmək — üzərinə klikləyin, fayl kompüterinizə saxlanılır.
5
Fayl göndərmək — faylı kompüterinizdən brauzer pəncərəsinə sürükleyib buraxın.
6
Geri qayıtmaq — ↑ düyməsini basın və ya yuxarıdakı çörək qırıntısı yolunda qovluğa klikləyin.
Skrinşot: fayl meneceri (07_files.png)

8. Proseslər və xidmətlər

1
Proseslər nişanına keçin.
2
CPU və yaddaş istifadəsi ilə birlikdə işləyən bütün proqramların siyahısını görürsünüz.
3
Prosesə klikləyin → Məhv et düyməsini basın — proqramı məcburi dayandırın.
4
Xidmətlər alt-nişanı: Windows sistem xidmətlərini başladın, dayandırın və yenidən başladın.
5
İşlət sahəsi: proqram yolu və ya əmr yazın — uzaq kompüterdə işləyəcək.
Skrinşot: proses meneceri (08_processes.png)

9. Terminal

1
Terminal nişanına keçin.
2
Windows əmri yazın (cmd və ya PowerShell kimi) və Enter basın.
3
Əmr tam sistem hüquqları ilə uzaq kompüterdə icra edilir.

Nümunə əmrlər

dir C:\Users — qovluqdakı faylları siyahıla

tasklist — işləyən bütün proqramların siyahısı

ipconfig — şəbəkə parametrlərini göstər

sc query MspIscSvc — PROMETEY agent xidmətinin işlədiyini yoxla

Diqqət: Əmrlər tam sistem hüquqları ilə icra edilir. Diqqətli olun — yanlış əmr uzaq kompüterin işini poza bilər.
Skrinşot: terminal (09_terminal.png)

10. Avtomatik skrinşotlar

Agent hər 10 saniyədə bir avtomatik ekran görüntüsü çəkir (intervalı Parametrlərdə dəyişə bilərsiniz).

1
Skrinşotlar nişanına keçin.
2
Qalereyaya baxın — tam şəkli ön izləmək üçün kiçik şəkilə klikləyin.
3
Silmək üçün: skrinşotların yanındakı onay qutularını işarələyin → Sil basın.
Baxılan şəkil silindikdə ön izlər avtomatik bağlanır.
Skrinşot: skrinşot qalereyası (11_screenshots.png)

11. Səs yazısı

Agent uzaq kompüterin mikrofonundan səsi fasiləsiz qeyd edir. Yazılar 5 dəqiqəlik OGG seqmentləri kimi saxlanır.

1
Səs nişanına keçin.
2
Yazılmış faylların siyahısını görürsünüz — daxili pleyerdə dinləmək üçün fayla klikləyin.
3
Silmək üçün: faylları seçin → Sil basın.
Skrinşot: səs bölməsi (10_audio.png)

12. Windows hadisə jurnalı

1
Hadisə jurnalı nişanına keçin.
2
Windows sistem hadisələrini görürsünüz: xətalar, xəbərdarlıqlar, məlumat mesajları.
3
Mənbəyə görə filtrləyin: Tətbiq, Sistem, Təhlükəsizlik.
Hadisə jurnalı uzaq kompüterdəki problemləri diaqnoz etməyə kömək edir — məsələn, proqramın çökməsinin səbəbini tapmaq.
Skrinşot: hadisə jurnalı (12_eventlog.png)

13. Parametrlər

Parametrlər nişanında 4 səhifə var:

🔄
Yeniləmə
Yeni agent versiyasını yükləyin və uzaqdan yeniləyin — kompüterə fiziki giriş lazım deyil.
🌐
Yerləşdirmə
VPS server ünvanını və bağlantı otaq tokenini dəyişin.
⚙
Konfiqurasiya
Bütün agent parametrləri: skrinşot intervalı, səs keyfiyyəti və s.
🛡
Təhdid
Təhlükəsizlik monitorinqi parametrləri.

14. Bir neçə operator

  • Bir neçə operator eyni vaxtda panelə daxil ola bilər — hər biri öz istifadəçi adı və şifrəsi ilə.
  • Administrator hər operatorun müəyyən bölmələrə girişini məhdudlaşdıra bilər.
  • Hər operatorun bütün hərəkətləri @istifadəçi adı və vaxt damğası ilə Fəaliyyət jurnalına yazılır.

15. Problemlərin həlli

ProblemHəll
Agent "OFFLINE" göstərir 1. Hədəf kompüterin açıq olduğunu və internetə qoşulduğunu yoxlayın.
2. Brauzer səhifəsini yeniləyin.
3. Agent xidmətini yoxlayın: sc query MspIscSvc
Ekranı görmürəm 1. Ekran nişanında Başlat düyməsini basın.
2. FPS-i 5-10-a, Keyfiyyəti 50-yə azaldın.
3. Dayandır düyməsini basın, 3 saniyə gözləyin, yenidən Başlat basın.
Girişdə təhlükəsizlik xəbərdarlığı Bu normaldır. Ətraflı → Sayta keç düyməsini basın. Sistem özü-özünə imzalanmış sertifikat istifadə edir — məlumatlarınız şifrəlidir.
Stream idarəetmə düymələri işləmir 1. Chrome və ya Edge istifadə edin (tövsiyə edilir).
2. Əvvəlcə Fit/Fill düyməsini sınayın.
Səs pleyeri işləmir 1. Brauzerdə səsin bloklanmadığını yoxlayın (ünvan çubuğundakı dinamik ikonası).
2. Başqa bir səs faylını seçin.
Kömək lazımdır? PROMETEY-ə giriş verən sistem administratoru ilə əlaqə saxlayın.
