Overview
Что такое PROMETEY? What is PROMETEY? PROMETEY nədir?
🖥️
Агент на ПК PC Agent PC Agenti
Невидимая фоновая служба Windows на управляемом компьютере. Устанавливается один раз. Invisible background Windows service on the managed computer. Installed once. İdarə olunan kompüterdə görünməz fon Windows xidməti. Bir dəfə quraşdırılır.
☁️
VPS Ретранслятор VPS Relay VPS Relay
Зашифрованный сервер-ретранслятор. Соединяет агента с браузером оператора через TLS. Encrypted relay server. Bridges agent to operator's browser over TLS. Şifrəli relay server. Agent ilə operator brauzerini TLS üzərindən birləşdirir.
🌐
Браузер-панель Browser Panel Brauzer Paneli
Полный контроль из любого браузера. Установка не нужна — только URL. Full control from any browser. No install needed — just open a URL. İstənilən brauzerdən tam nəzarət. Quraşdırma yoxdur — sadəcə URL.
