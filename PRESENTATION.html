Система скрытого удалённого администрирования Covert Remote Administration System Gizli Uzaqdan İdarəetmə Sistemi

Full remote control of a computer through an ordinary browser. Runs invisible to the user. All data is encrypted. A relay server in another country hides the operator. Как устроена система How the system works Sistem necə işləyir

Три участника: Объект (компьютер под управлением), VPS-server (посредник в другой стране) и Оператор (вы, в браузере). Объект и оператор никогда не соединяются напрямую — только через сервер-посредник. Это ключевое для анонимности. Three participants: Target (the computer being controlled), VPS server (relay in another country) and Operator (you, in a browser). The target and operator never connect directly — only through the relay server. This is key for anonymity. Üç iştirakçı: Obyekt (idarə olunan kompüter), VPS-server (başqa ölkədə vasitəçi) və Operator (siz, brauzerdə). Obyekt və operator heç vaxt birbaşa bağlanmır — yalnız vasitəçi server vasitəsilə. Bu anonimliyə əsasdır.

Что происходит шаг за шагом Step by step walkthrough Addım-addım nə baş verir

1
Объект запускает агент при старте Windows Target starts the agent on Windows startup Obyekt Windows başladıqda agenti işə salır
Сервис WPnpSvc автоматически стартует как часть операционной системы. Никакого окна, иконки или уведомления — владелец компьютера ничего не замечает. The WPnpSvc service starts automatically as part of the OS. No window, icon, or notification — the computer owner notices nothing. WPnpSvc servisi əməliyyat sisteminin bir hissəsi kimi avtomatik başlayır. Heç bir pəncərə, ikon və ya bildiriş yoxdur — kompüter sahibi heç nə fərq etmir.
2
Объект подключается к VPS через зашифрованный канал Target connects to the VPS via an encrypted channel Obyekt şifrəli kanal vasitəsilə VPS-ə qoşulur
Исходящее соединение по протоколу HTTPS (WebSocket) на порт 443. Это стандартный веб-порт — не отличается от обычного сёрфинга. Файрволы и роутеры его не блокируют. Outgoing connection via HTTPS (WebSocket) on port 443. This is a standard web port — indistinguishable from regular browsing. Firewalls and routers don't block it. HTTPS (WebSocket) protokolu ilə 443 portuna çıxış əlaqəsi. Bu standart veb portudur — adi brauzerdən fərqlənmir. Firewall-lar və routerlər onu bloklamır.
3
Оператор входит в браузере на страницу VPS Operator logs in via browser to the VPS page Operator brauzerdə VPS səhifəsinə daxil olur
Вводит логин и пароль. VPS проверяет учётные данные (пароль хранится в зашифрованном виде). После входа открывается панель управления с доступными вкладками. Enters login and password. The VPS verifies credentials (password stored in encrypted form). After login, a control panel opens with available tabs. İstifadəçi adı və parolu daxil edir. VPS məlumatları yoxlayır (parol şifrəli saxlanılır). Giriş etdikdən sonra mövcud tablarla idarə paneli açılır.
4
Все команды проходят через VPS-посредник All commands pass through the VPS relay Bütün əmrlər VPS vasitəçisi ilə keçir
Оператор нажимает кнопку в браузере → команда шифруется → VPS передаёт её объекту → объект выполняет → результат возвращается по той же цепочке. Прямого соединения оператор↔объект нет никогда. Operator clicks a button → command is encrypted → VPS forwards it to the target → target executes → result comes back through the same chain. There is never a direct operator↔target connection. Operator düyməyə basır → əmr şifrələnir → VPS onu obyektə göndərir → obyekt icra edir → nəticə eyni zəncir ilə geri qayıdır. Operator↔obyekt arasında birbaşa əlaqə heç vaxt olmur.
5
Дополнительные модули загружаются из VPS в память объекта Additional modules are loaded from VPS into target's RAM Əlavə modullar VPS-dən obyektin yaddaşına yüklənir
Когда оператор открывает файловый менеджер или список процессов — объект скачивает зашифрованный модуль с VPS и запускает его прямо в оперативной памяти. На жёсткий диск объекта ничего не записывается. When the operator opens the file manager or process list — the target downloads an encrypted module from the VPS and runs it directly in RAM. Nothing is written to the target's hard drive. Operator fayl menecerini və ya proseslər siyahısını açdıqda — obyekt VPS-dən şifrəli modulu yükləyir və onu birbaşa RAM-da işə salır. Obyektin sabit diskine heç nə yazılmır.

Основной агент и дополнительные модули Main agent and additional modules Əsas agent və əlavə modullar

Система разделена на части: главный агент (всегда в памяти) и отдельные зашифрованные модули (загружаются по требованию). The system is split into parts: the main agent (always in memory) and separate encrypted modules (loaded on demand). Sistem hissələrə bölünüb: əsas agent (həmişə yaddaşda) və ayrıca şifrəli modullar (tələb üzrə yüklənir).

💡 Зачем делить на модули? Самые «подозрительные» команды (управление файлами, процессами, антивирусом) вынесены из главного файла. Антивирус сканирует файл на диске и не находит ничего лишнего. Модули живут только в памяти и исчезают при перезагрузке. 💡 Why split into modules? The most "suspicious" commands (file management, process control, antivirus) are removed from the main file. Antivirus scans the file on disk and finds nothing suspicious. Modules live only in RAM and vanish on reboot. 💡 Niyə modullara bölünür? Ən "şübhəli" əmrlər (fayl, proses, antivirus idarəetməsi) əsas fayldan çıxarılıb. Antivirus diskdəki faylı skan edir və heç nə şübhəli tapmır. Modullar yalnız yaddaşda yaşayır və yenidən başladıldıqda silinir.

Что умеет система What the system can do Sistemin imkanları

Все функции доступны через браузер. Не нужно устанавливать никакое ПО на компьютер оператора. All features are accessible through a browser. No software needs to be installed on the operator's computer. Bütün funksiyalar brauzer vasitəsilə əlçatandır. Operatorun kompüterinə heç bir proqram quraşdırmaq lazım deyil.

🖥️
Просмотр экрана в реальном времениReal-time screen viewReal vaxt rejimində ekrana baxış
Видите экран объекта прямо в браузере, как будто сидите рядом. Изображение обновляется непрерывно. Настраивается качество, частота кадров и масштаб. See the target's screen right in your browser as if sitting next to it. Image updates continuously. Quality, frame rate, and scale are adjustable. Obyektin ekranını birbaşa brauzerdə görürsünüz, sanki yanındasınız. Görüntü fasiləsiz yenilənir. Keyfiyyət, kadr sürəti və miqyas tənzimlənir.
Поток идёт через VPS-server. WebRTC P2P можно включить отдельно, настроив STUN/TURN-сервер. Stream goes through the VPS server. WebRTC P2P can be enabled separately by configuring a STUN/TURN server. Axın VPS-server vasitəsilə keçir. WebRTC P2P STUN/TURN serveri konfiqurasiya etməklə ayrıca aktivləşdirilə bilər.
🖱️
Управление мышью и клавиатуройMouse and keyboard controlSiçan və klaviatura idarəsi
Кликаете прямо по изображению экрана в браузере — объект реагирует. Можно нажимать клавиши, перемещать мышь, прокручивать страницы, открывать программы. Click directly on the screen image in your browser — the target reacts. You can press keys, move the mouse, scroll pages, open programs. Brauzerdəki ekran görüntüsünə birbaşa klikləyirsiniz — obyekt reaksiya verir. Düymələrə basa, siçanı hərəkət etdirə, səhifələri sürüşdürə, proqramlar aça bilərsiniz.

Файловый менеджерFile managerFayl meneceri
Просматривайте любые папки на компьютере объекта, включая системные и скрытые. Скачивайте нужные файлы себе, загружайте файлы на объект, удаляйте и переименовывайте. Browse any folders on the target computer, including system and hidden ones. Download files to yourself, upload files to the target, delete and rename. Sistem və gizli qovluqlar da daxil olmaqla obyekt kompüterin istənilən qovluğunu nəzərdən keçirin. Lazımlı faylları özünüzə yükləyin, obyektə fayl yükləyin, silin və adını dəyişdirin.

Видите все запущенные программы и службы Windows в реальном времени. Можно завершить любую программу, запустить новую или изменить тип запуска службы. See all running programs and Windows services in real time. You can terminate any program, launch a new one, or change a service's startup type. Real vaxtda işləyən bütün proqramları və Windows servislərini görürsünüz. İstənilən proqramı bitirə, yeni birini başlada və ya servisin başlanma növünü dəyişə bilərsiniz.

Полноценный терминал (cmd/PowerShell) прямо в браузере. Выполняйте любые команды от имени системы с максимальными правами. Результат виден мгновенно. Full-featured terminal (cmd/PowerShell) right in the browser. Execute any command as SYSTEM with maximum privileges. Results appear instantly. Birbaşa brauzerdə tam terminal (cmd/PowerShell). Maksimum icazələrlə sistem adından istənilən əmrləri icra edin. Nəticə dərhal görünür.

Реестр WindowsWindows registryWindows Reyestri
Полный доступ к реестру Windows: просматривайте, создавайте, изменяйте и удаляйте любые ключи и значения. Все типы данных поддерживаются. Full access to the Windows registry: view, create, edit, and delete any keys and values. All data types are supported. Windows reyestrinə tam giriş: istənilən açar və dəyərləri baxın, yaradın, dəyişdirin və silin. Bütün məlumat növləri dəstəklənir.

Автоматические скриншотыAutomatic screenshotsAvtomatik ekran görüntüləri
Объект автоматически делает снимки экрана через заданный интервал и сохраняет их на VPS. Можно настроить: каждые N секунд, только определённые программы, качество и размер. The target automatically takes screen snapshots at a set interval and saves them to the VPS. Configurable: every N seconds, only specific apps, quality and size. Obyekt müəyyən edilmiş aralıqda avtomatik ekran görüntüsü çəkir və onları VPS-də saxlayır. Tənzimlənir: hər N saniyədə bir, yalnız müəyyən proqramlar, keyfiyyət və ölçü.

Запись микрофона и системного звука. Файлы сохраняются на VPS сегментами. Live-режим: слушайте прямой звук через браузер. Иконка микрофона в трее не появляется. Microphone and system audio recording. Files saved to VPS in segments. Live mode: listen to live audio through the browser. Microphone icon in the tray does not appear. Mikrofon və sistem sesinin yazılması. Fayllar VPS-də seqmentlər şəklində saxlanılır. Canlı rejim: brauzer vasitəsilə birbaşa səsi dinləyin. Tepsidə mikrofon ikonu görünmür.

История активности объектаTarget activity historyObyektin aktivlik tarixi
Система фиксирует: когда объект включён, выключен, ушёл в сон, заблокировал экран. Аналитика: суммарное время работы, количество сессий, статистика за период. The system records when the target is on, off, asleep, or screen-locked. Analytics: total uptime, session count, period statistics. Sistem qeyd edir: obyektin nə vaxt yandığını, söndüyünü, yuxuya getdiyini, ekranı kiliddlədiyini. Analitika: ümumi işləmə müddəti, sessiya sayı, dövr statistikası.

Управление операторамиOperator managementOperator idarəetməsi
Создавайте нескольких операторов с разными правами: кто-то видит только экран и файлы, кто-то имеет полный доступ. Каждый входит под своим логином. Create multiple operators with different permissions: some see only the screen and files, others have full access. Each logs in with their own credentials. Müxtəlif icazələrlə bir neçə operator yaradın: kimisi yalnız ekran və faylları görür, kimisi tam girişə malikdir. Hər biri öz girişi ilə daxil olur.

Обновление агента через браузерAgent update via browserAgent yeniləməsi brauzer vasitəsilə
Загрузите новую версию агента через браузер — объект скачает её, заменит старую и перезапустится. Физический доступ к компьютеру объекта не нужен. Upload a new agent version via the browser — the target downloads it, replaces the old one, and restarts. No physical access to the target is needed. Brauzerdən agentin yeni versiyasını yükləyin — obyekt onu yükləyib köhnəni əvəz edərək yenidən başlayacaq. Obyektin kompüterinə fiziki giriş lazım deyil.

Change agent settings on the target directly from the browser: stream quality, audio parameters, screenshot interval. Changes apply without reinstallation. Brauzerdən birbaşa obyektdəki agent parametrlərini dəyişdirin: axın keyfiyyəti, audio parametrləri, ekran görüntüsü aralığı. Dəyişikliklər yenidən quraşdırma olmadan tətbiq edilir.

One button — and the agent is completely removed from the target: service stopped, files deleted, registry entries cleared. The operation is irreversible. Bir düymə — agent obyektdən tamamilə silinir: servis dayandırılır, fayllar silinir, reyestr qeydləri təmizlənir. Əməliyyat geri alınmazdır.
