Часть 2

Полный функционал

Всё что умеет система — простым языком. Каждая функция доступна через браузер оператора.

🖥️
Стриминг экрана
Прямая трансляция рабочего стола хоста в браузер. Поддержка JPEG (до 95%), H.264 аппаратно или VP8. Настраиваемые FPS, качество, масштаб. WebRTC (P2P) или WebSocket fallback.
DXGIH.264WebRTC
🖱️
Управление мышью и клавиатурой
Полный удалённый контроль. Кликай прямо по стриму в браузере — хост получает движения, клики, scroll, нажатия клавиш в реальном времени через SendInput.
SendInputReal-time
📁
Файловый менеджер
Просмотр любых директорий. Скачать или загрузить файлы напрямую. Удаление, переименование, создание папок. Поддерживает системные и скрытые папки.

Часть 3

Безопасность и скрытность

Многоуровневая защита: от шифрования сетевого трафика до обхода антивирусов и полной невидимости для пользователя хоста.

1
🌐 Сетевой уровень — TLS 1.3 + WSS
Весь трафик проходит через HTTPS/WSS с TLS 1.3. Без nginx нет доступа к WebSocket. Хост подключается только к одному VPS-эндпоинту. Никаких открытых портов на стороне хоста.
TLS 1.3 wss:// nginx reverse proxy Port 443 only No inbound ports
2
🔐 Аутентификация — PBKDF2 + Session tokens
Пароли хранятся как PBKDF2-HMAC-SHA256 (100 000 итераций, per-user 16-байт salt). Сессионные токены — 24 байта urlsafe random. Живут в RAM сервера, теряются при рестарте. Хост доступен только с правильным room_token.
PBKDF2-HMAC-SHA256 100k iterations Per-user salt In-memory sessions room_token
3
🧩 Stage-2 — Зашифрованные модули в RAM
Самые «подозрительные» команды (файлы, процессы, defender) вынесены в отдельные .bin файлы. Они зашифрованы AES-256-GCM с ключом, специфичным для каждой комнаты. Загружаются в память через Reflective DLL Loading. На диске хоста никаких следов модулей нет.
AES-256-GCM Per-room key Reflective Load RAM only No disk artifacts
4
🛑 Обход антивирусов (AV Evasion)
Несколько уровней защиты от статического и динамического анализа:
/DELAYLOAD — 17 DLL скрыты из IAT NUL-byte scrub OpenSSL fingerprints VERSIONINFO Microsoft Corporation Set-MpPreference → Stage-2 only Строки AV-сигнатур убраны из DLL Authenticode code signing
Elastic ML: Malicious (High) → Undetected. THOR YARA: Set-MpPreference → в Stage-2 (RAM).
5
👻 Невидимость для пользователя хоста
Пользователь за компьютером не видит и не слышит признаков работы агента:
Нет окон и трей-иконки Сервис замаскирован как WPnpSvc DLL выглядит как Microsoft Plug and Play Микрофон скрыт (нет иконки в трее) Нет звуков, всплывающих уведомлений Записи журнала Windows автоочищаются
6
🔒 Конфиг на диске зашифрован
Файл pnpext.sys содержит конфиг хоста (сервер, пароль, параметры). Он зашифрован AES-256-GCM + PBKDF2 — в открытом виде нигде не хранится. Даже при физическом доступе к диску прочитать конфиг без ключа невозможно.
AES-256-GCM on disk PBKDF2 key derivation No plaintext config
7
🧹 Самоочистка при остановке
При остановке сервиса Stage-2 модули выгружаются из памяти, временные файлы удаляются. CleanupUpdateArtifacts() чистит .old/.new файлы и pnp_cache. Никаких следов обновлений на диске.
Stage-2 RAM unload Artifact cleanup No update traces
🎙️ Почему микрофон невидим в трее
🔴
Стандартный путь
Обычно при захвате аудио Windows показывает оранжевую точку в системном трее и уведомление.
✅
Наш подход
WASAPI используется напрямую в контексте SYSTEM. Privacy indicator срабатывает только для сессии пользователя — не для SYSTEM service.
🔇
Нет иконки микрофона
Пользователь не видит никакого визуального индикатора записи аудио ни в трее, ни в настройках конфиденциальности.
📁
Файлы сохраняются на VPS
Аудиозаписи не остаются на диске хоста — сразу передаются и сохраняются на VPS-сервере.

Что и как зашифровано
🌐
Сетевой трафик
WSS / TLS 1.3. Все команды, ответы, скриншоты — в зашифрованном туннеле. Перехватить снаружи невозможно.
💾
Конфиг на диске
AES-256-GCM + PBKDF2. Файл pnpext.sys без знания ключа расшифровать нельзя.
🧩
Stage-2 блобы на VPS
AES-256-GCM с per-room ключом. Без правильного room_token модули не расшифруются.
🔑
Пароли пользователей
PBKDF2-HMAC-SHA256 (100k iter). Даже при утечке users.json подобрать пароль крайне долго.
🎫
Сессии
24-байтовые urlsafe токены в RAM. Не сохраняются на диске, живут только во время работы сервера.
📡
WebRTC P2P поток
DTLS-SRTP шифрование. Прямое соединение браузер–хост без хранения данных на VPS.
