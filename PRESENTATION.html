Full remote control of a computer through an ordinary browser. Runs invisible to the user. All data is encrypted. A relay server in another country hides the operator. Как устроена система How the system works Як влаштована система

Три участника: Объект (компьютер под управлением), VPS-сервер (посредник в другой стране) и Оператор (вы, в браузере). Объект и оператор никогда не соединяются напрямую — только через сервер-посредник. Это ключевое для анонимности. Three participants: Target (the computer being controlled), VPS server (relay in another country) and Operator (you, in a browser). The target and operator never connect directly — only through the relay server. This is key for anonymity. Три учасники: Об'єкт (комп'ютер під управлінням), VPS-сервер (посередник в іншій країні) та Оператор (ви, у браузері). Об'єкт і оператор ніколи не з'єднуються напряму — лише через сервер-посередник. Це ключове для анонімності.

Что происходит шаг за шагом Step by step walkthrough Що відбувається крок за кроком

1
Объект запускает агент при старте Windows Target starts the agent on Windows startup Об'єкт запускає агент при старті Windows
Сервис WPnpSvc автоматически стартует как часть операционной системы. Никакого окна, иконки или уведомления — владелец компьютера ничего не замечает. The WPnpSvc service starts automatically as part of the OS. No window, icon, or notification — the computer owner notices nothing. Сервіс WPnpSvc автоматично стартує як частина ОС. Жодного вікна, іконки чи сповіщення — власник комп'ютера нічого не помічає.
2
Объект подключается к VPS через зашифрованный канал Target connects to the VPS via an encrypted channel Об'єкт підключається до VPS через зашифрований канал
Исходящее соединение по протоколу HTTPS (WebSocket) на порт 443. Это стандартный веб-порт — не отличается от обычного сёрфинга. Файрволы и роутеры его не блокируют. Outgoing connection via HTTPS (WebSocket) on port 443. This is a standard web port — indistinguishable from regular browsing. Firewalls and routers don't block it. Вихідне з'єднання за протоколом HTTPS (WebSocket) на порт 443. Це стандартний веб-порт — не відрізняється від звичайного серфінгу. Файрволи і роутери його не блокують.
3
Оператор входит в браузере на страницу VPS Operator logs in via browser to the VPS page Оператор входить у браузері на сторінку VPS
Вводит логин и пароль. VPS проверяет учётные данные (пароль хранится в зашифрованном виде). После входа открывается панель управления с доступными вкладками. Enters login and password. The VPS verifies credentials (password stored in encrypted form). After login, a control panel opens with available tabs. Вводить логін і пароль. VPS перевіряє облікові дані (пароль зберігається в зашифрованому вигляді). Після входу відкривається панель управління з доступними вкладками.
4
Все команды проходят через VPS-посредник All commands pass through the VPS relay Всі команди проходять через VPS-посередник
Оператор нажимает кнопку в браузере → команда шифруется → VPS передаёт её объекту → объект выполняет → результат возвращается по той же цепочке. Прямого соединения оператор↔объект нет никогда. Operator clicks a button → command is encrypted → VPS forwards it to the target → target executes → result comes back through the same chain. There is never a direct operator↔target connection. Оператор натискає кнопку → команда шифрується → VPS передає її об'єкту → об'єкт виконує → результат повертається тим самим ланцюжком. Прямого з'єднання оператор↔об'єкт немає ніколи.
5
Дополнительные модули загружаются из VPS в память объекта Additional modules are loaded from VPS into target's RAM Додаткові модулі завантажуються з VPS у пам'ять об'єкта
Когда оператор открывает файловый менеджер или список процессов — объект скачивает зашифрованный модуль с VPS и запускает его прямо в оперативной памяти. На жёсткий диск объекта ничего не записывается. When the operator opens the file manager or process list — the target downloads an encrypted module from the VPS and runs it directly in RAM. Nothing is written to the target's hard drive. Коли оператор відкриває файловий менеджер або список процесів — об'єкт завантажує зашифрований модуль з VPS та запускає його прямо в оперативній пам'яті. На жорсткий диск об'єкта нічого не записується.

Основной агент и дополнительные модули Main agent and additional modules Основний агент та додаткові модулі

Система разделена на части: главный агент (всегда в памяти) и отдельные зашифрованные модули (загружаются по требованию). The system is split into parts: the main agent (always in memory) and separate encrypted modules (loaded on demand). Система поділена на частини: головний агент (завжди в пам'яті) та окремі зашифровані модулі (завантажуються за потребою).

💡 Зачем делить на модули? Самые «подозрительные» команды (управление файлами, процессами, антивирусом) вынесены из главного файла. Антивирус сканирует файл на диске и не находит ничего лишнего. Модули живут только в памяти и исчезают при перезагрузке. 💡 Why split into modules? The most "suspicious" commands (file management, process control, antivirus) are removed from the main file. Antivirus scans the file on disk and finds nothing suspicious. Modules live only in RAM and vanish on reboot. 💡 Навіщо ділити на модулі? Найбільш "підозрілі" команди (керування файлами, процесами, антивірусом) винесені з головного файлу. Антивірус сканує файл на диску і нічого зайвого не знаходить. Модулі живуть лише в пам'яті і зникають при перезавантаженні.

Что умеет система What the system can do Що вміє система

Все функции доступны через браузер. Не нужно устанавливать никакое ПО на компьютер оператора. All features are accessible through a browser. No software needs to be installed on the operator's computer. Всі функції доступні через браузер. Не потрібно встановлювати жодного ПЗ на комп'ютер оператора.

Просмотр экрана в реальном времениReal-time screen viewПерегляд екрану в реальному часі
Видите экран объекта прямо в браузере, как будто сидите рядом. Изображение обновляется непрерывно. Настраивается качество, частота кадров и масштаб. See the target's screen right in your browser as if sitting next to it. Image updates continuously. Quality, frame rate, and scale are adjustable. Бачите екран об'єкта прямо в браузері, наче сидите поруч. Зображення оновлюється безперервно. Налаштовуються якість, частота кадрів та масштаб.
Поток идёт через VPS-сервер. WebRTC P2P можно включить отдельно, настроив STUN/TURN-сервер. Stream goes through the VPS server. WebRTC P2P can be enabled separately by configuring a STUN/TURN server. Потік іде через VPS-сервер. WebRTC P2P можна увімкнути окремо, налаштувавши STUN/TURN-сервер.

Click directly on the screen image in your browser — the target reacts. You can press keys, move the mouse, scroll pages, open programs. Клікаєте прямо по зображенню екрану в браузері — об'єкт реагує. Можна натискати клавіші, переміщати мишу, прокручувати сторінки, відкривати програми.
