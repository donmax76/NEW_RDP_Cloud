Добро пожаловать в PROMETEY Welcome to PROMETEY PROMETEY-ə Xoş Gəldiniz

PROMETEY — это система удалённого доступа, которая позволяет наблюдать за Windows-компьютером и управлять им через любой веб-браузер, из любой точки мира. Никакого дополнительного программного обеспечения на стороне оператора не требуется — достаточно браузера. PROMETEY is a remote access system that lets you monitor and control a Windows computer from any web browser, over the internet. No software installation is required on the operator's side — just a browser. PROMETEY, istənilən veb-brauzer vasitəsilə, dünyanın istənilən nöqtəsindən Windows kompüterini izləmək və idarə etmək imkanı verən uzaqdan giriş sistemidir. Operator tərəfindən heç bir əlavə proqram tələb olunmur — yalnız brauzer kifayətdir.

Раздел 1Section 1Bölmə 1

Установка агента Agent Installation Agent Quraşdırması

Агент устанавливается на целевой Windows-компьютер один раз. После этого он автоматически запускается как служба Windows при каждом старте системы — физическое присутствие больше не нужно. The agent is installed on the target Windows computer once. After that it runs automatically as a Windows service on every system start — no physical presence required after that. Agent hədəf Windows kompüterinə bir dəfə quraşdırılır. Bundan sonra hər sistem başlanğıcında Windows xidməti kimi avtomatik işə düşür — fiziki iştirak artıq tələb edilmir.
