Раздел 1 Section 1 Bölmə 1

Установка агента Agent Installation Agent Quraşdırması

Агент устанавливается на компьютер объекта один раз. После установки он автоматически запускается при каждом старте Windows и поддерживает постоянное соединение с VPS. The agent is installed on the target computer once. After installation it starts automatically on every Windows boot and maintains a persistent connection to the VPS. Agent obyekt kompüterinə bir dəfə quraşdırılır. Quraşdırıldıqdan sonra hər Windows başlanğıcında avtomatik işə düşür və VPS ilə daimi əlaqəni saxlayır.

pnpext.sys Зашифрованный конфиг (адрес VPS, токен, пароль). Читается только агентом.Encrypted config (VPS address, token, password). Readable only by the agent.Şifrəli konfiq (VPS ünvanı, token, parol). Yalnız agent tərəfindən oxunur.

Servis quraşdırmaq üçün Windows administrator hüquqları tələb olunur. Skript UAC-ı avtomatik olaraq tələb edir.

Вход в панель оператора Logging into the Operator Panel Operator Panelinə Giriş

Панель оператора — это обычная веб-страница. Никакого ПО устанавливать не нужно. Работает в любом современном браузере. The operator panel is an ordinary web page. No software needs to be installed. Works in any modern browser. Operator paneli adi bir veb-səhifədir. Heç bir proqram quraşdırmaq lazım deyil. İstənilən müasir brauzerdə işləyir.

1
Откройте браузер и перейдите по адресу VPSOpen a browser and go to the VPS addressBrauzeri açın və VPS ünvanına keçin
Адрес выдаёт администратор. Обычно это https://IP-адрес на порт 443. Браузер может показать предупреждение о сертификате — нажмите «Продолжить».The address is provided by the admin. Usually https://IP-address on port 443. The browser may show a certificate warning — click "Continue".Ünvanı administrator verir. Adətən https://IP-ünvan 443 portunda. Brauzer sertifikat xəbərdarlığı göstərə bilər — "Davam et" düyməsini basın.
2
Введите имя пользователя и парольEnter your username and passwordİstifadəçi adı və şifrənizi daxil edin
Учётные данные выдаёт администратор. Пароль чувствителен к регистру. При ошибке появится сообщение «Неверный пароль».Credentials are issued by the admin. The password is case-sensitive. An incorrect entry shows "Wrong password".Giriş məlumatları administrator tərəfindən verilir. Parol böyük/kiçik hərflərə həssasdır. Səhv girişdə "Yanlış parol" mesajı görünəcək.

Если объект не в сети — значок красный, команды в очереди.If the agent is online, a green "Online" badge with the machine name appears in the header. 🔐 Безопасность сессииSession securitySessiya təhlükəsizliyi
Каждая сессия использует уникальный одноразовый токен, который хранится только в памяти сервера. При перезапуске VPS все сессии сбрасываются — потребуется войти снова. Each session uses a unique one-time token stored only in server RAM. When the VPS restarts all sessions are cleared — you will need to log in again. Hər sessiya yalnız server yaddaşında saxlanılan unikal birdəfəlik token istifadə edir. VPS yenidən başladıldıqda bütün sessiyalar sıfırlanır — yenidən daxil olmalısınız.

The image updates continuously at the configured frame rate. Obyektin iş masasını real vaxt rejimində göstərir. Görüntü konfiqurasiya edilmiş kadr sürəti ilə fasiləsiz yenilənir.

💡 WebRTC P2P
Для низкой задержки можно включить WebRTC P2P в настройках (раздел «STUN/TURN»). Требует настройки STUN/TURN-серверов. В штатном режиме стрим идёт через VPS — задержка ~200–400 мс в зависимости от расстояния. For low latency, enable WebRTC P2P in settings (STUN/TURN section). Requires STUN/TURN server configuration. In standard mode the stream goes through the VPS — ~200–400 ms delay depending on distance. Aşağı gecikmə üçün parametrlərdə (STUN/TURN bölməsi) WebRTC P2P-ni aktivləşdirin. STUN/TURN serverlərinin konfiqurasiyasını tələb edir. Standart rejimdə strim VPS vasitəsilə gedir — məsafədən asılı olaraq ~200–400 ms gecikmə.

🔊 Системный звук в окне стримаSystem audio in stream windowStrim pəncərəsində sistem səsi

Кнопка 🔊 SYS (в верхней панели окна стрима или в наложении) включает live-трансляцию системного звука объекта прямо в браузер. Используется WASAPI loopback — захватывается весь звук, воспроизводимый на объекте (игры, видео, системные звуки), без отображения индикатора микрофона. The 🔊 SYS button (in the stream window toolbar or overlay) enables live streaming of the target's system audio directly to the browser. Uses WASAPI loopback — captures all audio playing on the target (games, video, system sounds) without triggering the microphone indicator. 🔊 SYS düyməsi (strim pəncərəsinin alət çubuğunda və ya yerləşdirmədə) obyektin sistem sesini birbaşa brauzerdə canlı yayımlamağı aktivləşdirir. WASAPI loopback istifadə edir — mikrofon göstəricisini tetiklemeden obyektdə çalınan bütün səsi (oyunlar, video, sistem səsləri) tutur.

Рекомендации по безопасности Security Recommendations Təhlükəsizlik Tövsiyələri

🔴 Защита VPSVPS protectionVPS mühafizəsi
VPS — самое уязвимое звено. Используйте сложный пароль SSH, отключите парольную аутентификацию, оставьте только ключи. Регулярно меняйте пароли операторов. The VPS is the most vulnerable link. Use a strong SSH password, disable password authentication, leave only keys. Regularly change operator passwords. VPS ən həssas həlqədir. Güclü SSH parolu istifadə edin, parol autentifikasiyasını söndürün, yalnız açarlar buraxın. Operator parollarını mütəmadi dəyişdirin.
💡 Периодически меняйте токен комнатыPeriodically change the room tokenVaxtaşırı otaq tokenini dəyişdirin
Токен комнаты (room_token) — идентификатор объекта на VPS. При подозрении на компрометацию — смените токен, перегенерируйте pnpext.sys и переустановите агент. The room token (room_token) is the target identifier on the VPS. If compromise is suspected — change the token, regenerate pnpext.sys and reinstall the agent. Otaq tokeni (room_token) VPS-dəki obyektin identifikatorudur. Kompromis şübhəsi varsa — tokeni dəyişdirin, pnpext.sys-i yenidən yaradın və agenti yenidən quraşdırın.
